실시간 DB 연결

무료 Firebase Realtime Database를 연결하면 모든 기기에서 피클들이 실시간으로 함께 써요.

이렇게 준비해요
  1. console.firebase.google.com 에서 새 프로젝트를 만들어요.
  2. 빌드 → Realtime Database → 데이터베이스 만들기를 눌러요. (위치는 가까운 곳)
  3. 규칙을 아래처럼 바꿔요. 테스트용으로 열어두는 설정이에요.
{
  "rules": {
    ".read": true,
    ".write": true
  }
}

프로젝트 설정 → 내 앱 → SDK 설정의 firebaseConfig 값을 위 칸에 그대로 붙여넣으면 끝이에요. 웹 앱의 apiKey는 공개되어도 되는 값이지만, 위 규칙은 누구나 쓸 수 있는 설정이라 개인정보는 올리지 마세요.

🤖 AI 동료 연결

무료로 쓸 수 있는 Google Gemini 키를 넣으면 비서실의 AI 동료 제미나이가 대답해요.

사용할 AI
무료 키 만드는 법 (카드 등록 없이)
  1. Google AI Studio에 구글 계정으로 로그인해요.
  2. API 키 만들기를 눌러 AIza... 로 시작하는 키를 복사해요.
  3. 위 칸에 붙여넣고 연결 테스트 → 저장을 눌러요.
키는 이 브라우저에만 저장돼요
  • 키는 localStorage에만 있고, GitHub · Firebase로는 절대 전송되지 않아요.
  • 대화를 요청할 때만 generativelanguage.googleapis.com으로 키가 전달돼요.
  • 이 브라우저를 쓰는 사람은 키를 쓸 수 있으니, 공용 기기에서는 지워주세요.

채팅이나 화이트보드에서 @제미나이 · @gemini · @ai 라고 부르거나, 입력창의 🤖 버튼을 켜두면 대답해요. 무료 등급은 1분에 몇 번, 하루 수백 번까지 넉넉해요.

키는 이 브라우저에만 저장돼요
  • 키는 localStorage에만 있고, GitHub · Firebase로는 절대 전송되지 않아요.
  • 대화를 요청할 때만 api.openai.com으로 키가 전달돼요.
  • 이 브라우저를 쓰는 사람은 키를 쓸 수 있으니, 공용 기기에서는 지워주세요.

키는 platform.openai.com → API keys 에서 만들 수 있어요. 채팅에서 @챗지피티 라고 부르거나, 입력창의 🤖 버튼을 켜두면 대답해요.
